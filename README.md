# Terraria-Luck-Mechanic-Simulator


A C++ implementation of the Terraria luck mechanic. User can input a luck value and a sample 1 in n probability to see how positive and negative luck affects the chance of an event occuring.


I will make the program a GUI in the future.

More on the luck mechanic on the official wiki: 
https://terraria.wiki.gg/wiki/Luck
